# 短视频文案专家 · Short Video Script Pro（v1.3）

> **开源基础版** ｜ 方法论与规则支持：**AI 改造家杰克**

一套面向 AI Agent（Claude Code / Codex / Antigravity / 各类支持项目指令的 AI 工具）的开源短视频写稿与原素材粗剪 Skill。

专门解决创作者、老板和内容团队最常见的两大痛点：
1. **单篇原稿太长、太书面、铺垫太慢**，发到短视频平台没人看、留不住人；
2. **10～60 分钟长访谈/已拍口播转写做粗剪时**，ASR 错别字满屏、口癖去不干净、逻辑松散拖沓，剪不出高完播的短视频。

把你的单篇原稿或长访谈转写直接丢给 AI，它会自动完成 **语音转写选型建议 & 上下文语义纠偏 →（长篇先）全文打标签与选题拆池 → 围绕单一认知跃迁按六大流量原理重构压缩 → 双轴冷审**，输出**可直接上提词器或按时间码直接进剪映粗剪的高完播成片**与 **3 组互补开头三兄弟**。

## 一、v1.2 新增核心能力（单篇打磨强化 × 长访谈粗剪闭环）

在完整保留 v1.0 / v1.1 单篇原意顺稿（B1）与原素材粗剪能力的基础上，v1.2 重点补齐了真实生产中的三大断层：

1. **前置转写选型推荐 + 上下文语义纠偏（单篇、长篇全部受益）**
   - 按电脑配置、隐私需求与预算，给出高准确率＋支持说话人分离的转写推荐（本地离线 `FunASR + CAM++` / `MLX-Whisper large-v3-turbo` / `SenseVoice`，云端高性价比 `豆包 / 阿里 Paraformer API`，以及零代码 `飞书妙记 / 通义听悟 / 剪映`），避免低准确率听写污染源头。
   - **双层分离纠偏**：模式 A+ 严守「原声不编造实词」，但**必须**在字幕与可读稿层修正高置信 ASR 同音/术语错字，并透明输出《ASR 上下文纠错对照表》与《待核听疑点》。
2. **长篇/访谈强制「全文打标签 → 选题拆池 → 聚焦粗剪」流水线**
   - 超过 1,000 字或 3 分钟的访谈/直播/长稿，先逐段打标签（`强数字/反差钩子`、`核心观点`、`硬证据`、`跨回合可复用`、`官话淘汰`），再拆出按优先级排序的选题候选池，主动淘汰低流量机构套话段，杜绝把 15 分钟群访硬揉成一条长流水账。
3. **模式 A+ 活字重组粗剪（零新增字符 × 词/字级逻辑重构）**
   - 把经语义纠偏后的原稿视为**「活字字盘」**：在 100% 满足 `validate_roughcut.py --asr-map` 零新增字符校验的前提下，允许最细到**词与单字级**的排列重组——彻底洗净结巴病句与口癖，从字盘精准调取 `但 / 所以 / 说明 / 第一二三四` 补齐转折缺口与并列对齐（总领前置＋主干完整＋人话收口），单条稳压 **45～90 秒**高完播区；
   - 支持多说话人访谈（提问人压成 ≤10 秒锐问钩子 / 纯嘉宾后文最强反差句倒装开场），输出含 `说话人` 与精确时间码的剪辑分段表，并可按需生成**左原文打标 × 右成片粗剪**的单文件 HTML 审稿页。

## 二、实测效果：把 2,200 字长文压成 70 秒高完播脚本

以一篇 2,200 字的 AI 工具深度长文为例（原稿开头在聊多款云端产品和环境配置，支线繁多），直接丢进本 Skill 的默认 `B1 顺稿模式` 后：

- **长度压缩**：2,200 字书面长文 → **340 字（约 70 秒）**单命题高密度口播
- **人群开口**：从「极客圈云端 Agent 对比」→ 翻成所有 AI 用户一秒看懂的反差首句：**「用 AI 最容易踩的坑，不是买贵了，而是退不出来。」**
- **开头三兄弟（自动生成 3 组互补，推荐组如下）**：
  - **标题**：别把你的工作积累，全喂给一个 AI 账号
  - **视频描述**：按月付费随时能停，但你调教好的标准和资料，换个工具可能全得重来。连官方文档都写明了：能导出，不等于能迁移。
  - **正文首句**：用 AI 最容易踩的坑，不是买贵了，而是退不出来。
- **结构与节奏**：删掉全部宏观铺垫与旁支，只留「买贵 vs 退不出 → 点一下停订阅 vs 搬走积累难 → 官方文档硬证据（能导出 ≠ 能迁移）→ 普通文件解法＋小任务测试 → 核心原则收口」，每 1～3 句推进一次认知，停在最强句。

## 三、这套 Skill 到底帮你优化什么？（六大核心流量维度）

不同于普通的「帮我改得更有网感」提示词，本 Skill 把短视频流量原理拆成了可逐项冷审的六道硬标准（详见 [references/six-dimensions.md](references/six-dimensions.md)）：

1. **结构**：一条视频只完成**一次认知跃迁**；长稿先打标拆「选题候选池」，强制执行**逐接缝逻辑检查**（上句留下的预期 → 下句必须接住，杜绝跳步和强行用「所以」硬缝）。
2. **节奏**：每 1～3 句必须发生认知状态变化；内置**三轮反向压缩**（整拍删除 → 同拍句子竞争 → 句内字词裁切），专治原稿太长、原地解释和结尾拖尾。
3. **字词**：把「写出来看的字」改成「说出来听的话」；删掉作文过渡词、授课腔和浮夸 AI 营销腔，把最有力量的话落在句尾。
4. **人群基数**：区分核心 / 发散 / 泛三层人群漏斗；把只有同行听得懂的专业术语翻译成大众熟悉的日常场景、现实代价或结果，默认把公域流量做大。
5. **元素印象组合**：用具体数字、价格、身份、正反日常场景形成紧邻反差，拒绝平铺罗列和空洞说教。
6. **开头三兄弟**：标题、视频描述、正文首句作为三个独立广告位分别打磨、严禁复读，默认给出 3 组不同人群与情绪切入角度并推荐一组。

同时内置 **强制双轴冷审（流量结构审＋对象感口吻审）** 与 **多轮修改防退化机制**（详见 [references/review-and-iteration.md](references/review-and-iteration.md)）：严禁编造经历、数据或收益承诺；修改反馈只做局部最小补丁，不推翻已经顺畅的好段落。

## 四、30 秒安装与上手

### 1. 安装方式

- **Claude Code / Codex / Antigravity 用户**：
  ```bash
  git clone https://github.com/JackyChen2013/short-video-script-pro.git ~/.agents/skills/short-video-script-pro
  ```
  （如你的工具读取 `~/.claude/skills/`，克隆或软链到该目录即可。）
- **网页版 AI（ChatGPT / Claude / Gemini / 豆包等）**：
  下载本仓库的 `SKILL.md` 及 `references/` 下三份手册，上传为项目知识或系统指令即可使用。

### 2. 零门槛直接使用（最常用 4 句指令）

无需提前写复杂档案，直接把原稿或转写丢给 AI 即可：

1. **单篇原稿太长，按流量原理压成高完播短脚本（默认首选）**
   > 「用 short-video-script-pro 的 B1 顺稿模式优化这篇原稿：如果有语音转写错别字请先结合上下文纠偏，保留我的原意和自然口吻，重点压短时长，按六大流量维度重构，先做大流量版本。」
2. **长访谈 / 直播转写，先打标签拆选题池，再聚焦粗剪**
   > 「这是一段长访谈转写，请先做 ASR 上下文语义纠偏与全文打标签，拆出选题候选池并标出建议淘汰的官话段；我选好后再按模式 A+ 输出 45–90 秒可剪时间码清单。」
3. **单条已拍视频、不编造原话只做逻辑重构粗剪（模式 A+）**
   > 「用模式 A+ 对这段已拍视频的带时间码转写做原素材粗剪：原声零编造实词，但请按上下文修正字幕同音错字并附纠错对照表；清理口癖时保留原声里的逻辑连接词，按新顺序输出可剪分段表。」
4. **局部微调（防退化）**
   > 「整体已经很顺了，请冻结当前稿件，只帮我调整第 2 段和第 3 段的衔接，把结尾再压短一点。」

## 五、开源基础版 vs 专业版（搭配 IP 资产与策略系统）

**本仓库提供的是「开源基础版」**，核心目标是帮创作者**零门槛跑通单条短视频的公域大流量，以及长访谈的打标粗剪闭环**。

但如果你已经有成熟业务、正在打造长期个人 IP，跑出播放量后很快会遇到更深一层的问题：**「怎么让来的流量更精准？怎么把公域大流量自然转成客户成交？怎么让 AI 写出来的每条稿子都像你本人、还能调用你的真实案例？」**

这些问题单靠通用写稿 Skill 很难解决，需要搭配完整的 **IP 资产与内容策略系统（专业版）** 一起用，效果会完全不同：

| 对比维度 | 开源基础版（本仓库免费使用） | 专业版：搭配 IP 资产与策略系统 |
|---|---|---|
| **核心目标** | 单条内容**流量最大化** ＋ 长访谈打标粗剪 | **前流后转与精准成交**（既要大流量，更要来对客户） |
| **前置输入** | 直接丢原稿或转写，零门槛上手 | 接入专属 **IP 资产库**（定位、三层人群漏斗、已核实案例与产品矩阵） |
| **个人风格** | 通用自然口播、去 AI 味 | 定制 **IP 语言指纹** ＋ 历史实拍校准回归，越用越像本人 |
| **转化设计** | 纯流量收口，不强加广告 | 按业务机制设计 **成交子弹** 与 **前流后转转化模型** |
| **生产深度** | 文案顺稿、打标拆池与时间码粗剪表 | 支持剪映工程直连、音频声学切点精修与批量内容工厂流水线 |
